# Persian VPN UI 🇮🇷

A modern and beautiful VPN client user interface built with pure HTML, CSS, and Vanilla JavaScript. This project simulates a real VPN connection experience.

## ✨ Features
- 🌙 Modern Dark Mode Design
- 🔌 Simulated Connection Handshake (Delay)
- 📊 Real-time Speed Fluctuation (Download/Upload)
- 🌐 Fake IP & Ping Display
- 🗺️ Multiple Server Locations (Germany, Netherlands, etc.)
- 🇮🇷 Fully RTL (Right-to-Left) Support for Persian

## 🚀 How to Run
Simply open `index.html` in your web browser. No server or build tools required!

> ⚠️ **Disclaimer:** This is a **frontend simulator only**. It does NOT establish a real VPN connection or change your IP address.
